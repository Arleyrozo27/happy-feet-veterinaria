# 🐕 Sistema de Gestión Happy Feet Veterinaria

Sistema integral de gestión para clínica veterinaria desarrollado en Java con arquitectura MVC.

## 🚀 Características

- **Gestión de Dueños y Mascotas**
- **Sistema de Citas Inteligente** 
- **Control de Inventario en Tiempo Real**
- **Módulo de Facturación**
- **Base de Datos MySQL**

## 🛠️ Tecnologías

- Java 17
- Maven
- MySQL
- JDBC
- Principios SOLID
- Patrones de Diseño

## 📋 Requisitos

- JDK 17 o superior
- MySQL 8.0+
- Maven 3.6+
